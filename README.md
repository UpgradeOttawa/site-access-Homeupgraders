# Home Upgraders website: review copy

A read-only copy of the finished **homeupgraders.ca website files**, shared so reviewers and tools (Gemini, other AI assistants, SEO checkers) can read them. It contains only website pages and their stylesheet. It does not contain the apps (apps.homeupgraders.ca), planning notes, or server files.

This is **not** the master copy and is not deployed from here. Changes are made elsewhere and this copy is refreshed from it.

## Layout
- `index.html`: homepage (new design, preview)
- `about-us/`, `contact-us/`, `gallery/`, `services/` (index plus 8 service pages): one `index.html` each
- `css/style.css`: shared stylesheet for every page except the homepage (the homepage has its own styles inside the file)
- `404.html`, `robots.txt`, `sitemap.xml`, `.htaccess`, `assets/`, `gallery/photos.json`

## For reviewers
- Keep every URL (path and trailing slash) exactly as is.
- Keep titles, meta descriptions, canonicals and visible text unless a change is requested.
- Use "third generation" for the business. The owner's son is described as the fourth generation, working alongside him.
- Report findings; please do not rewrite page copy or invent claims (awards, licences, warranties, project counts, reviews).
